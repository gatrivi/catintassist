## #0 — THE real pain (user, 10-20): "I press ES opener, nothing happens"
Interpreter POV, mid-call: you press, you get no signal, and you only find out it failed when the patient yells.
Silent paths in `OnCallSoundboardStrip.js` `fireClip`:
- `play()` / sink errors → `catch` = `console.error` only, **no UI** (`:422`)
- passthrough cancelled for any reason except `sink_changed` → silent return
- every other notice is a 3.5 s flash (`:235`), easy to miss while you're talking
- **even on success there's no proof it reached the cable.** The ▶ progress bar only shows the file playing, not what went out.

Fix, from → to:
| From | To |
|------|----|
| Press → maybe ▶ bar | Press → tile shows **3 states, always**: `SENDING` (amber) → `ON AIR` + live **output** meter, measured on the sink stream → `SENT ✓ 3.2s` (green, stays 5 s) |
| Error → console | Error → tile turns red with a **one-line reason + one fix button** (stays until you tap) |
| Output meter flat for 1 s while "playing" | `⚠ SILENT — nothing reached the cable` (red) |
| CALL OK missing → 🔒 chip far from the tile | Reason shown **on the tile you pressed** |

# UX/UI pass 2 (v4.190.0 code) — is it as simple as it can be? **No.**

## What an interpreter does: press the ES opener mid-call
Today: look for the strip → **expand it** (collapsed can't fire anything) → find the tile among ≤8 → press → read status in
**one of 4 places** (LIVE span, send chip, 🔒 block chip, 3.5 s notice).
Target: **press `ES` on the bar → read the same button.** 1 tap, 1 place.

## Collapsed bar: up to 14 things on one 32 px line
| Element | On-call use | Verdict |
|---|---|---|
| `▸ Greetings · Morning` toggle | expand | keep as `▾` only |
| LIVE span | duplicate of send chip | **merge** |
| send chip (v4.190) | status | **merge into 1 status slot** |
| 🔒 block chip + Test it | status | **merge** |
| 3.5 s notice | status | **merge** (nothing flashes) |
| AM / PM / Eve / A picker (4 btns) | rare, the clock decides | → ⚙ menu |
| `☀ using Morning` cue | duplicate of `2/3` chip | **delete** |
| EN / ES readiness chips (v4.189) | info only | **become the fire buttons** |
| 🔇 Hear | rare | → ⚙ menu |
| ⏹ Stop | while playing | keep |

Expanded strip adds: tile-size slider (never needed on-call → delete), Monitor checkbox (**duplicate** of Hear → delete),
per tile: lang badge + ○ + variant icon + label (4 marks → 1 label + 1 color).

## Words the user shouldn't need
`CALL OK`, `route`, `sink`, `passthrough`, `legibility`, `VB out`. → **Ready / Not tested / Not recorded / Silent.**

## Process to make a greeting usable (off-call)
Today: record (3 places: Studio Setup, Editor, Studio gallery) → health check → Hear → Send → confirm CALL OK —
**per clip family × per device id**. A device re-enumerating = redo all of it.
Target: **record in the Editor only. Test the output ONCE** ("Test my output" → beep through cable → meter → ✓).
A clip is Ready = recorded + output tested. Health stays as a hint, never a gate.

## Target design (from → to)
```
FROM (collapsed, worst case)
▸ Greetings · Morning ▶LIVE·Opener–LEP │SENDING│ AM PM Eve A │☀ using Morning│ EN 2/3 │ ES 🔒 │🔇 Hear│⏹ Stop│🔒 …not verified (CALL OK) [Test it][×]

TO
╔══════════════════════════════════════════════════════╗
║ ◆ EN   ◆ ES  │  ON AIR · ES opener ▮▮▮▯▯   ⏹  │ ▾  ⚙ ║
╚══════════════════════════════════════════════════════╝
```
- `◆ EN` / `◆ ES` **fire the openers directly**, collapsed. Color = state: gold ready · amber missing a time slot ·
  red not recorded / not tested (tap = says why, offers fix off-call).
- **One status slot**: SENDING → ON AIR ▮ → SENT ✓ / red NOT SENT + reason. Nothing else ever talks.
- `▾` = the other picked greetings (tiles: label + color only). `⚙` = time slot, Hear, pick greetings.
- Art deco: black/ivory, brass hairline frame, stepped corners, caps labels (Poiret One / Josefin), 4 colors total.

## Order (each its own small ship)
1. **Openers fire from the collapsed bar + one status slot** (biggest daily win, removes ~8 elements)
2. Move AM/PM/Eve, Hear, size, Monitor into ⚙; delete duplicates
3. "Test my output" once → replaces per-clip CALL OK (needs care: it's the safety gate)
4. Plain words everywhere
5. Art deco skin
6. Editor = only place to record; Studio = gallery + backup
