Study cue cards (between calls + hold) — v1

1. Data model — `src/utils/studyDecks.js`
   - Card types: `glossary` (en, es, domain), `nosay` (wrong → right, e.g. "aseguranza → seguro"), `acronym` (abbr, expansion, translation), `qa` (reminder text).
   - Domains: auto, insurance, education, utilities, financial, social, medical, plus `all`.
   - Decks stored as static JS arrays (like `medicalTermLexicon.js`), one file per batch or one combined file with domain tags.

2. Deck cleanup — `scripts/clean-glossary.js` (or test-time validator)
   - Dedupe by normalized EN term (airbag, appointment, driver's license), flag missing ES / broken entries, output clean JSON + report. Runs before deck ships; add a jest test asserting no dupes/empties in the shipped deck.

3. Card component — `src/components/StudyCueCards.js`
   - Rotating card in the idle pane: front (EN term / prompt) → ES answer with reveal/flip; tap or auto-advance.
   - Random rotation per domain; no spaced repetition in v1 (structure fields so it can be added later).

4. Integration
   - `OffCallWorkspace.js`: in healthy-idle branch, cue cards supersede `showRotatingTip`; during `isHold && isActive`, cards overlay/fade in over the transcript pane background.
   - Register `study_cue_cards` in `componentVisibility.js` (default `off_call` mode) so it respects the newbie-guide/visibility gating.

5. Domain picker — small selector chip row on the card itself (or in condensed toolbar)
   - Persist via `catint_study_domain_v1` localStorage key + change event, following `AudioSettingsContext` idiom.

6. Version + tests
   - New version pill entry (e.g. v4.88.0) with feature message.
   - Tests: deck validator (dupes/empties), card picker (domain filtering, rotation determinism with seed), persistence round-trip.
   - Run full test suite; refactor; commit + push if green.
